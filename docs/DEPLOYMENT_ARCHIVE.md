# Deployment Archive

The OncoVax hosted baseline deployment was archived before DigitalOcean shutdown on 2026-08-09.

The hosted deployment was used to demonstrate Docker runtime, nginx reverse proxy configuration, Grafana/Influx observability, API health behaviour, external uptime monitoring and DigitalOcean firewall/runtime controls.

The live Droplet was removed for cost control after the student cloud credit no longer covered the deployment. Source code, Docker configuration, nginx configuration, runbooks, recovery documentation, screenshots and final runtime inventory remain in this repository.

Archived evidence is stored in:

`docs/deployment-evidence/2026-08-09-digitalocean-shutdown/`

Sensitive runtime values are intentionally excluded. The archive does not include `.env` files, API tokens, passwords, private keys, database credentials or TLS private keys.
